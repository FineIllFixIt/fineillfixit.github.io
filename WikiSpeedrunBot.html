Wikipedia Speedrun Bot

I created a wikipedia speedruning bot that can go between any two english wikipedia pages in just a few seconds.

Visit the github repo for this project here.

Overview

I created a wikipedia speedrunning bot. I mapped the entirety of wikipedia then use a bidirectional breadth first search to find a path between any two pages. I then used autotesting software to control a web browser to navigate the path found. It typically only takes a few seconds for the bot to go between any two pages.
